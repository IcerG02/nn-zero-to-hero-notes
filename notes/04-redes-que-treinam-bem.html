Bloco 1 de 5

A loss inicial

Antes de treinar, você já sabe qual número esperar. Se ele estiver muito diferente, algo está errado.

Bloco 1 · Loss inicial

No início, a rede deveria estar em dúvida

3,30
esperado: −ln(1/27), todas as letras igualmente prováveis
29,0
pesos sem escala: logits enormes, confiantes e errados
3,30
com W2 * 0.01 e b2 * 0
W2 = torch.randn((n_hidden, vocab_size), generator=g) * 0.01
b2 = torch.randn(vocab_size, generator=g) * 0

Com logits grandes, a softmax dá quase 100% para uma letra qualquer. Quando ela está errada, a loss explode. Os primeiros milhares de passos são gastos só desfazendo essa confiança: a curva em forma de "taco de hóquei" da Aula 03.

Os valores 29,0 e 3,30 do meio e da direita vêm de uma reprodução em NumPy, no conjunto de treino inteiro.

Bloco 2 de 5

tanh saturada

Mesmo com a loss inicial certa, a camada escondida pode estar quebrada por dentro.

Bloco 2 · tanh saturada

Quando a tanh satura, o gradiente desaparece

A derivada local da tanh é 1 − t² (Aula 01). Se a saída t está perto de ±1, a derivada é quase zero, e o gradiente que chega naquele neurônio é multiplicado por quase zero.

Com pesos W1 e b1 sem escala, a pré-ativação tem desvio-padrão perto de 4,9: a maior parte dos valores cai na parte plana da curva.

Neurônio morto

Se um neurônio está saturado para todos os exemplos, ele nunca recebe gradiente e nunca aprende. Karpathy encontra esses neurônios procurando colunas inteiras com |h| > 0,99.

Bloco 3 de 5

A escala certa

Trocar o chute "0,2" por uma regra: Kaiming.

Bloco 3 · Escala

Cada multiplicação de matriz muda a escala

x = torch.randn(1000, 10)
w = torch.randn(10, 200)
y = x @ w                     # y.std() ≈ 3,09

w = torch.randn(10, 200) / 10**0.5
y = x @ w                     # y.std() ≈ 0,98

Cada saída soma 10 produtos de variância 1, então a variância vira 10 e o desvio-padrão vira √10 ≈ 3,16. Dividindo os pesos por √fan_in, a escala se mantém em 1.

Inicialização de Kaiming

std(W) = ganho / √fan_in. O ganho compensa o quanto a não linearidade "encolhe" o sinal: para tanh, 5/3; para ReLU, √2.

W1 = torch.randn((30, 200), generator=g) * (5/3) / 30**0.5
# no PyTorch: torch.nn.init.kaiming_normal_

Valores 3,09 e 0,98 da minha reprodução. O nome vem de Kaiming He, autor do artigo que analisou essas escalas.

Bloco 3 · Escala

Em cinco camadas, o ganho decide tudo

GanhoCamada 5Saturação

Ganho baixo: o sinal encolhe camada a camada até sumir. Ganho alto: 40% das saídas saturam. 5/3 fica estável. A BatchNorm estabiliza sem precisar acertar o ganho.

Bloco 4 de 5

BatchNorm

Se queremos pré-ativações com média 0 e desvio 1, por que não simplesmente normalizá-las?

Bloco 4 · BatchNorm

Normalizar a pré-ativação dentro do batch

hpreact = embcat @ W1                     # sem b1: veja ao lado

bnmeani = hpreact.mean(0, keepdim=True)   # média de cada neurônio no batch
bnstdi  = hpreact.std(0, keepdim=True)
hpreact = bngain * (hpreact - bnmeani) / bnstdi + bnbias

with torch.no_grad():                      # para usar na inferência
    bnmean_running = 0.999 * bnmean_running + 0.001 * bnmeani
    bnstd_running  = 0.999 * bnstd_running  + 0.001 * bnstdi

Cada neurônio é normalizado com a média e o desvio do batch atual. Isso é diferenciável, então o backprop passa por ela normalmente.

bngain e bnbias são aprendidos: a rede pode desfazer a normalização onde for útil.

O viés antes da BN é inútil

Qualquer viés somado antes é subtraído junto com a média. Por isso b1 sai; o bnbias faz o papel dele.

Bloco 4 · BatchNorm

Os efeitos colaterais da BatchNorm

Os exemplos ficam acoplados

A saída de um exemplo passa a depender dos outros 31 do batch. Isso adiciona um pequeno ruído que, por acaso, funciona como regularização.

Inferência precisa de estatísticas fixas

Para prever um único exemplo não há batch. Usa-se a média e o desvio acumulados no treino: as running stats, atualizadas por média móvel sem gradiente.

Armadilha clássica

Esquecer de pôr a rede em modo de avaliação (layer.training = False, ou model.eval() no PyTorch). A rede passa a normalizar com as estatísticas do batch de teste, e os números mudam com o tamanho do batch.

No notebook, a conta da BN com estatísticas fixas dá treino 2,0674 e validação 2,1057.

Bloco 4 · BatchNorm

O placar dos consertos

Corrigir a confiança inicial e a saturação já vale 0,07. Kaiming empata com o ajuste manual, mas é uma regra, não um chute. A BatchNorm não melhora este modelo raso.

Por que usar BN, então?

Numa rede rasa, uma boa inicialização basta. Numa rede profunda é quase impossível acertar todos os ganhos à mão, e é aí que a BN paga a conta.

Bloco 5 · Diagnóstico

Camadas com a mesma API do torch.nn

class Linear:
    def __init__(self, fan_in, fan_out, bias=True):
        self.weight = torch.randn((fan_in, fan_out), generator=g) / fan_in**0.5
        self.bias = torch.zeros(fan_out) if bias else None
    def __call__(self, x):
        self.out = x @ self.weight
        if self.bias is not None:
            self.out += self.bias
        return self.out
    def parameters(self):
        return [self.weight] + ([] if self.bias is None else [self.bias])

layers = [
  Linear(30, 100, bias=False), BatchNorm1d(100), Tanh(),
  Linear(100, 100, bias=False), BatchNorm1d(100), Tanh(),
  # ... mais 3 blocos iguais ...
  Linear(100, 27, bias=False), BatchNorm1d(27),
]   # 47.024 parâmetros

Cada camada guarda sua saída em self.out. Isso não é necessário para treinar, mas permite olhar dentro da rede depois de cada passo.

As classes Linear, BatchNorm1d e Tanh espelham nn.Linear, nn.BatchNorm1d e nn.Tanh. Ao migrar para o PyTorch de verdade, quase nada muda.

O hábito

No notebook, a rede de 5 camadas com BN mostra desvio de 0,63 a 0,65 em todas as tanh e saturação abaixo de 3%. É esse retrato que você quer ver antes de gastar horas treinando.

Fechamento

A aula em seis linhas

  • Loss inicial deve ser −ln(1/27) ≈ 3,30. Muito acima: logits confiantes demais → encolha a última camada.
  • tanh saturada mata o gradiente (1 − t² ≈ 0). Olhe a fração de |h| > 0,99.
  • Escala: multiplicar por uma matriz multiplica o desvio por √fan_in.
  • Kaiming: std = ganho / √fan_in, ganho 5/3 para tanh.
  • BatchNorm normaliza por batch, aprende ganho e viés, e usa running stats na inferência.
  • Diagnóstico: ativações, gradientes, gradiente:dado e atualização:dado (≈ 10⁻³).

Responda antes de clicar

1Qual deveria ser a loss no primeiro passo de um modelo com 27 classes? Por quê?
−ln(1/27) ≈ 3,30. Sem ter aprendido nada, a rede deveria dar a mesma probabilidade para todas as letras.
2Por que uma tanh saturada impede o aprendizado?
A derivada local é 1 − t². Com t ≈ ±1 ela é quase zero, e o gradiente que passa pelo neurônio some. Se ele satura para todos os exemplos, nunca aprende.
3Qual desvio-padrão usar nos pesos de uma camada tanh com 30 entradas?
(5/3) / √30 ≈ 0,30: o ganho da tanh dividido pela raiz do fan-in.

4Por que a camada linear antes de uma BatchNorm não precisa de viés?
